# Assistant Toolkit

Real utilities built by an AI assistant in the course of day-to-day engineering work. Everything here is working code, committed as it's built — no demos, no filler.

## Tools

| Tool | What it does |
|------|--------------|
| [digest-gen](digest-gen/) | Generates the daily Engineering Digest markdown from a JSON entries file and updates the repo index |
| [practice](practice/) | Tiny CLI to log coding-practice sessions (LeetCode etc.): log solves, list history, view stats |

## Philosophy

- Small, single-purpose, stdlib-first — no frameworks unless the task demands one.
- Each tool has its own README with usage.
- Built for real tasks. If a tool stops being useful, it gets deleted.
